\# 🌍 Real-Time Clock Dashboard



A modern, responsive world clock dashboard built with \*\*React and Vite\*\*, designed to display real-time information across different time zones through a clean and interactive interface.



🚀 \*\*Live Demo:\*\* \[View Real-Time Clock Dashboard](https://misbah435.github.io/real-time-clock-dashboard-react/)



\## ✨ Features



\- 🕒 \*\*Real-Time Clock\*\* – Displays continuously updated time.

\- 🕰️ \*\*Analog \& Digital Clocks\*\* – Multiple clock display formats.

\- 🌎 \*\*World Time Zones\*\* – View time across different locations.

\- ⏰ \*\*Alarm Management\*\* – Set and manage alarms.

\- 📱 \*\*Responsive Design\*\* – Works across desktop and mobile devices.

\- 🎨 \*\*Modern Interface\*\* – Clean and user-friendly dashboard.



\## 🛠️ Technologies Used



| Technology | Purpose |

\## 💻 Run Locally



\*\*1. Clone the repository\*\*



```bash

git clone https://github.com/misbah435/real-time-clock-dashboard-react.git

```



\*\*2. Navigate into the project\*\*



```bash

cd real-time-clock-dashboard-react

```



\*\*3. Install dependencies\*\*



```bash

npm install

```



\*\*4. Start the development server\*\*



```bash

npm run dev

```



\*\*5. Open the local URL\*\*



Visit the URL displayed in your terminal, usually:



`http://localhost:5173`



\## 🏗️ Production Build



To create an optimized production build:



```bash

npm run build

```



To preview the production build locally:



```bash

npm run preview

```



\## 🌐 Deployment



This project is deployed using GitHub Pages.



To deploy your latest changes:



```bash

npm run deploy

```
